# IAM Dungeon Architecture

## Project Goal

IAM Dungeon is a learning project designed to teach:

* C#
* .NET
* APIs
* JSON
* SQL
* Git
* GitHub

through a role-playing game focused on Identity and Access Management (IAM) concepts.

---

# Learning Strategy

For every concept learned:

1. Understand what it does.
2. Understand why it exists.
3. Understand when it should be used.
4. Build a working example.
5. Commit the milestone to GitHub.

No code should be copied without understanding what every line does.

---

# Week 1 - Dungeon 01: Village Registry

## Scenario

You are the registrar for the kingdom of WonderLa.

Every adventurer entering the kingdom must be registered before gaining access to quests, equipment, and protected areas.

This dungeon serves as the foundation for learning core C# programming concepts.

---

## Learning Objectives

### Variables and Data Types

Learn to declare and use:

* `string`
* `int`
* `decimal`
* `bool`

### Arithmetic Operators

| Operator | Purpose             | Example  |
| -------- | ------------------- | -------- |
| `+`      | Addition            | `2 + 3`  |
| `-`      | Subtraction         | `5 - 2`  |
| `*`      | Multiplication      | `4 * 3`  |
| `/`      | Division            | `10 / 2` |
| `%`      | Remainder (modulus) | `10 % 3` |

### Comparison Operators

| Operator | Meaning                  |
| -------- | ------------------------ |
| `==`     | Equal to                 |
| `!=`     | Not equal to             |
| `>`      | Greater than             |
| `<`      | Less than                |
| `>=`     | Greater than or equal to |
| `<=`     | Less than or equal to    |

### Logical Operators

| Operator | Meaning |
|----------|----------|
| `&&` | AND |
| `||` | OR |
| `!`  | NOT |

### Program Flow

Learn to use:

* `if`
* `if/else`
* `switch`
* `while`
* `for`
* `foreach`

### Methods

Learn to:

* Create methods
* Call methods
* Pass parameters
* Return values

### Debugging

Use Visual Studio to:

* Set breakpoints
* Step Into
* Step Over
* Inspect variable values
* Follow execution flow

### Troubleshooting

Learn to identify and resolve:

* Compiler errors
* Runtime exceptions
* Logic errors

# Week 1 Success Criteria

By the end of Week 1, you should be able to:

* Create and run a C# console application.
* Declare and use variables of different data types.
* Perform arithmetic calculations.
* Use comparison and logical operators.
* Make decisions using `if/else` and `switch`.
* Repeat actions using loops.
* Create and call methods.
* Debug a program using Visual Studio.
* Identify and fix compiler, runtime, and logic errors.
* Commit progress to GitHub with meaningful commit messages.

---

## End of Week 1 Deliverable

A working WonderLa Registry console application that demonstrates:

* User input and output
* Variables and data types
* Arithmetic calculations
* Conditional logic
* Loops
* Methods
* Basic debugging practices

The application should be fully understood by the developer and committed to GitHub as a record of learning progress.
